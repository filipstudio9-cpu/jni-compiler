# JNI Compiler

**JNI Compiler** — инструмент для Android-разработчиков, работающих с JNI и нативным кодом. Упрощает компиляцию, сборку и интеграцию C/C++ компонентов в Android-приложения.

[![Предзаказ в RuStore](https://img.shields.io/badge/RuStore-Предзаказ-blue)](https://www.rustore.ru/catalog/app/com.jnicompiler.app)

## О проекте

JNI Compiler создан для того, чтобы убрать рутину при работе с JNI. Он помогает быстрее собирать нативные библиотеки, проверять корректность заголовков и интегрировать native-код в Android-проект.

Приложение уже доступно для предзаказа в RuStore.

## Возможности

- Компиляция JNI-кода
- Работа с C и C++
- Поддержка CMake и Android NDK
- Генерация и проверка JNI-заголовков
- Удобная интеграция с Android-проектами
- Понятные сообщения об ошибках
